CAD Work Assistant 0.9.0 Release Candidate

1. Run CADWorkAssistant-Setup-0.9.0-RC-x64.exe.
2. Complete the installer.
3. Launch CAD Work Assistant.
4. Open Settings to confirm Version 0.9.0, Release Candidate, Data Location, and User Manual.
5. See the installed user manual PDF for detailed usage.

Supported target:
- Windows x64
- AutoCAD 2024 CAD workflows

Notes:
- Internet, AI, API keys, login, and license activation are not required.
- This RC is unsigned. Windows SmartScreen may show a warning.
- User data is preserved when the application is uninstalled.
- Real AutoCAD validation is pending; test important DWG workflows on backup copies first.

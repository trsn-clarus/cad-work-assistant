CAD Work Assistant Third-Party Notices

This file summarizes direct runtime third-party packages used by CAD Work Assistant 0.9.0 RC. Test-only packages are not distributed in the user package.

Runtime packages:

- ClosedXML 0.105.1
  Used for Excel .xlsx generation.
  License: MIT.

- PDFsharp-MigraDoc 6.2.4
  Used for PDF report and user manual generation.
  License: MIT.

- Microsoft.Data.Sqlite 8.0.8
  Used for local SQLite data storage.
  License: MIT.

- Serilog 4.0.2 and Serilog.Sinks.File 6.0.0
  Used for local application logging.
  License: Apache-2.0.

- System.Text.Json 8.0.5
  Used for local IPC message serialization.
  License: MIT.

Autodesk AutoCAD managed host DLLs are referenced for plugin compilation but are not redistributed in the CAD Work Assistant package.
